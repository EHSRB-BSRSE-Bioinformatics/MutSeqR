# A comprehensive list of mutation subtypes at different resolutions

A comprehensive list of mutation subtypes at different resolutions

## Usage

``` r
subtype_list
```

## Format

A list with corresponding values

## Examples

``` r
subtype_list[["type"]]
#> [1] "ambiguous"     "complex"       "deletion"      "insertion"    
#> [5] "mnv"           "no_variant"    "sv"            "snv"          
#> [9] "uncategorized"
subtype_list[["base_6"]]
#> [1] "C>A" "C>G" "C>T" "T>A" "T>C" "T>G"
```

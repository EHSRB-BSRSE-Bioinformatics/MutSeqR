# A list of reference contexts at different resolutions

A list of reference contexts at different resolutions

## Usage

``` r
context_list
```

## Format

A list with corresponding values

## Examples

``` r
context_list[["base_6"]]
#> [1] "C" "T"
context_list[["base_12"]]
#> [1] "A" "C" "G" "T"
```

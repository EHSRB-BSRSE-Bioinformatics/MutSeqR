# Dictionary of column name synonyms for required mutation data columns

A list of column specifications

## Usage

``` r
op
```

## Format

A list with potential variable column names

## Value

A list containing column-name aliases, required mutation-data columns,
site columns, and default mutation-processing settings.

## Examples

``` r
# examples of "alt" synonyms
op$column$alternate
#> [1] "alt"
```

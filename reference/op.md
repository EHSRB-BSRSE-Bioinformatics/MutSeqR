# Dictionary of column name synonyms for required mutation data columns

A list of column specifications

## Usage

``` r
op
```

## Format

A list with potential variable column names

## Examples

``` r
# examples of "alt" synonyms
op$column$alternate
#> [1] "alt"
op$column$alt_value
#> [1] "alt"
op$column$tumor_seq_allele2
#> [1] "alt"
```
